# [BUG] Ghi nhớ đăng nhập — Cookie `autologin` thiếu cờ HttpOnly, script trên trang đọc được

## Thông tin chung
- **ID:** BUG_login_1791897547_TC071
- **Severity:** 🟠 Major
- **Priority:** P2
- **Nền tảng:** `web`
- **Môi trường:** Demo dùng chung `https://crm.anhtester.com` | Chromium 156 (Playwright MCP, headed) | macOS | viewport 1600×770
- **Build / Version:** `app.version = 316` (build của lần chạy phát hiện `run_1791625292`, theo `docs/requirements/README.md`)
- **Test case liên quan:** `CRM_LOGIN_TC_071`
- **REQ ID liên quan:** `REQ-LOGIN-63` (tách từ `REQ-LOGIN-23`, PO xác nhận là lỗi — `AMB-LOGIN-05`)
- **Test data đã dùng:** Tài khoản `EMAIL_ADMIN` trong `.env` (người chạy tự nhập mật khẩu), có tích `Remember me`
- **Ngày phát hiện:** 10-10-2026 · tái hiện lại 13-10-2026

## Steps to Reproduce
1. Mở cửa sổ ẩn danh mới, vào `https://crm.anhtester.com/admin/authentication`
2. Đăng nhập bằng tài khoản Staff hợp lệ, **tích** `Remember me` → vào Dashboard
3. DevTools → Application → Cookies: xem cột `HttpOnly` của cookie `autologin`
4. DevTools → Console: chạy `document.cookie.includes('autologin')`

## Expected Result
Cookie `autologin` có `HttpOnly` = bật; `document.cookie` **không** chứa `autologin` (REQ-LOGIN-63, cùng chuẩn với cookie phiên `sp_session` — REQ-LOGIN-20).

## Actual Result
- `autologin`: `HttpOnly` = **tắt** · `Secure` = bật · `SameSite=Lax` · hạn còn 62 ngày
- `document.cookie` **có** chứa `autologin` → mọi script trên trang (kể cả script bị chèn qua một lỗ XSS) đọc được dấu ghi nhớ đăng nhập 62 ngày

## Evidence
- Thuộc tính cookie đo bằng công cụ ngày 13-10-2026 (không chép giá trị cookie): `{ httpOnly: false, secure: true, sameSite: "Lax", daysLeft: 62 }` · `document.cookie` chứa `autologin` = `true`
- Ảnh trang không thể hiện được thuộc tính cookie — chi tiết lần chạy gốc: [execution_report.md — FAIL #10](../../../executions/login/web/run_1791625292/execution_report.md)

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn (2/2 lần)
- **Workaround (nếu có):** Không tích `Remember me`
- **Nghi ngờ root cause (nếu phân tích được):** Lệnh set cookie `autologin` không truyền tham số `httponly = true` (cookie phiên `sp_session` thì đã có `HttpOnly`)
- Liên quan `AMB-LOGIN-12`: Logout không xoá cookie `autologin` khỏi trình duyệt — PO chấp nhận, nhưng làm cookie chứa `user_id` tồn tại lâu hơn
