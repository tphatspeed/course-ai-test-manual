## Steps to Reproduce
1. Chưa đăng nhập, mở `https://crm.anhtester.com/admin/authentication/reset_password` (không kèm tham số)

## Expected Result
Hiện trang **404** của hệ thống, mã phản hồi `404`; không phải trang lỗi máy chủ (REQ-LOGIN-64, PO chốt ở AMB-LOGIN-28).

## Actual Result
Mã phản hồi `500`; Chrome hiện trang `This page isn’t working … HTTP ERROR 500`.

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn (3/3 lần)
- **Workaround (nếu có):** Không ảnh hưởng luồng đúng — chỉ gặp khi liên kết đặt lại bị hỏng / cắt cụt
- **Nghi ngờ root cause (nếu phân tích được):** Action `reset_password` dùng tham số (staff / user id, mã đặt lại) mà không kiểm thiếu trước → lỗi PHP chưa bắt
- Ca liên kết đúng định dạng nhưng **sai** tham số chưa kiểm được — định dạng thật chỉ có trong email (`RISK-LOGIN-03`)
