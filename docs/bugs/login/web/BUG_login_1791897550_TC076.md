# [BUG] Đăng nhập (quản trị) — Ô Email và Password thiếu thuộc tính autocomplete

## Thông tin chung
- **ID:** BUG_login_1791897550_TC076
- **Severity:** 🟢 Trivial
- **Priority:** P3
- **Nền tảng:** `web`
- **Môi trường:** Demo dùng chung `https://crm.anhtester.com` | Chromium 156 (Playwright MCP, headed) | macOS | viewport 1600×770
- **Build / Version:** `app.version = 316` (build của lần chạy phát hiện `run_1791625292`, theo `docs/requirements/README.md`)
- **Test case liên quan:** `CRM_LOGIN_TC_076`
- **REQ ID liên quan:** `REQ-LOGIN-70` (PO xác nhận là lỗi — `AMB-LOGIN-21`; không áp cho Login cổng — `AMB-LOGIN-27`)
- **Test data đã dùng:** Không
- **Ngày phát hiện:** 10-10-2026 · tái hiện lại 13-10-2026

## Steps to Reproduce
1. Mở `https://crm.anhtester.com/admin/authentication`
2. DevTools → Console (bật mức Verbose): đọc cảnh báo `[DOM]`
3. DevTools → Elements: xem thuộc tính `autocomplete` của `#email` và `#password`

## Expected Result
Không có cảnh báo của Chrome về thiếu `autocomplete` · `#password` có `autocomplete="current-password"` · `#email` có `autocomplete` khác rỗng (REQ-LOGIN-70).

## Actual Result
Cả hai ô **không** có thuộc tính `autocomplete`; Console có cảnh báo của Chrome.

## Evidence
- Đo ngày 13-10-2026: `#email.getAttribute('autocomplete')` = `null` · `#password.getAttribute('autocomplete')` = `null`
- Console:
  ```
  [VERBOSE] [DOM] Input elements should have autocomplete attributes (suggested: "current-password"): (More info: https://goo.gl/9p2vKq) %o @ https://crm.anhtester.com/admin/authentication:0
  ```
- Thuộc tính DOM không thể hiện được trên ảnh trang — chi tiết lần chạy gốc: [execution_report.md — FAIL #11](../../../executions/login/web/run_1791625292/execution_report.md)

## Ghi chú thêm
- **Tần suất tái hiện:** Luôn luôn (mọi lần mở trang)
- **Workaround (nếu có):** Không cần — trình quản lý mật khẩu vẫn điền được nhưng kém chính xác
- **Nghi ngờ root cause (nếu phân tích được):** Template form Login quản trị chưa khai báo `autocomplete` cho hai thẻ `input`
